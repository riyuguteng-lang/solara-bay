Solara Bay is an original open-world crime game that runs entirely in the browser. It is set in a sun-soaked coastal city that you can explore on foot or behind the wheel, with traffic and pedestrians filling the streets, cars you can steal, a wanted level that brings the police after you, five story missions to work through, hand-to-hand and gun combat, a HUD with a minimap, and save support so your progress survives a reload. Everything here is original — no Rockstar or GTA names or assets.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in your browser.

### Controls

- **WASD** — move
- **Mouse** — look
- **Shift** — run
- **Space** — jump
- **E** — enter / exit car
- **F** — punch
- **1** — fists / **2** — pistol
- **Click** — shoot
- **R** — reload
- **P** — pause
- **M** — mute
